# 钢铁风暴 Steel Storm

一款 **RA2 红警风格玩法的原创 RTS 手机游戏**，纯 ArkTS + ArkUI Canvas 实现，单机对抗 AI，横屏运行于 HarmonyOS（API 12 / HarmonyOS 5.0+）。

> 说明：红警2 的美术素材、单位名称与剧情属 EA 版权，本项目为**原创设定与程序化绘制美术**，复刻的是其经典玩法框架：等距视角、基地建造、采矿经济、电力系统、暴兵对攻。

## 运行步骤

1. 安装 **DevEco Studio 5.0+**（含 HarmonyOS SDK API 12）。
2. `File → Open` 打开本目录（SteelStorm 工程根）。
3. 首次打开等待 hvigor 同步完成。
4. 连接鸿蒙真机或启动模拟器，菜单 `File → Project Structure → Signing Configs` 勾选 **Automatically generate signature** 自动签名。
5. 点击 Run ▶ 安装运行（应用强制横屏 + 全屏 + 屏幕常亮）。

## 玩法

- **目标**：摧毁红方（AI）所有建筑即胜；己方建筑全灭则负。
- **经济**：采矿车自动在矿区（金色晶簇）与矿石精炼厂之间循环，采满 700 资金回厂卸货。多建精炼厂+矿车可提升收入。
- **电力**：顶栏显示 `电力 消耗/产出`。耗电超过产出时，所有生产速度降至 45%，防御炮塔停机。
- **建造**：右侧「建筑」页点击开始建造（同时只能造一个）；完成后**点击地图空地放置**（需靠近己方建筑、地形空旷且已探索）。绿色幽灵=可放置，红色=不可。
- **造兵**：右侧「部队」页点击训练。步兵出兵营，载具（含采矿车）出战车工厂，各 4 格队列。
- **操作**：
  - 拖动屏幕 = 平移视角；点击左上小地图 = 跳转视角
  - 点击己方单位 = 选中；「全选部队」= 选中全部作战单位
  - 选中后点击地面 = 移动（自动编队散开）；点击敌人 = 攻击
  - 「停止 / 取消选择」= 停止当前指令并清空选择
- **AI**：会按序扩张基地、补充发电厂与炮塔、每隔约 95 秒发动规模递增的进攻波次，基地遇袭时会回防反击。

## 工程结构

```
entry/src/main/ets/
├── entryability/EntryAbility.ets   # 横屏全屏入口
├── pages/Index.ets                 # UI页面：Canvas + 触控 + 侧边栏
└── game/
    ├── Config.ets    # 数值配置表（所有平衡性调整集中在此）
    ├── World.ets     # 地图生成 / 矿区 / 战争迷雾 / A*寻路（8向禁切角）
    ├── Entities.ets  # 建筑 / 单位 / 炮弹 / 特效实体
    ├── Game.ets      # 引擎核心：主循环 / 经济 / 电力 / 生产 / 战斗 / AI
    └── Renderer.ets  # 等距渲染：地形 / 立体建筑 / 单位 / 小地图 / 放置预览
```

架构为单向数据流：`Config(数据) → World(空间) → Entities(状态) → Game(逻辑) → Renderer(表现) → Index(交互)`。游戏逻辑与渲染完全解耦，逻辑层不依赖任何 UI API，可独立做单元测试或换渲染后端。

## 扩展建议

- **平衡性**：直接改 `Config.ets` 的 BSPECS/USPECS 数值表即可，无需动逻辑。
- **新单位/建筑**：在 Config 加枚举与规格 → Renderer 加绘制分支即可，生产/战斗/AI 逻辑自动兼容。
- **性能**：当前 44×44 地图 + 全量重绘在主流机型 30fps 无压力；若扩大地图，可将地形层缓存到 OffscreenCanvas 只重绘动态层。
- **存档**：Game 类状态全部可序列化（无闭包引用），可接 Preferences 持久化。
- **多人**：逻辑层为确定性帧步进（dt 固定上限），具备改造为帧同步联机的基础。
